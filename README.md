# Captain's Sidestick — Android Controller

Flight simulator sidestick controller for X-Plane 12 and other simulators.
Turn your Android phone into a realistic Captain's sidestick.

## Features
- Gyroscope-based pitch and roll control
- Artificial horizon display
- Airbus-style throttle with MCT/FLEX/TOGA detents
- Rudder slider with auto-return to center
- PTT button for VATSIM
- Captain and Co-Pilot layouts
- Sensor lock for autopilot use
- WebSocket connection to PC app

## Requirements
- Android 6.0+
- Gyroscope sensor required
- Same WiFi network as PC

## Installation
1. Download latest APK from Releases
2. Enable "Install from unknown sources" in Android settings
3. Install APK
4. Install Captain's Sidestick PC app on your computer
5. Open both apps → scan QR code → fly
